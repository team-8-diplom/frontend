# Проект

Цифровая платформа для централизованного выбора тем дипломных работ, которая автоматизирует публикацию тем преподавателями и сопоставление студентов с релевантными темами на основе навыков.

## Запуск проекта

```
npm i
npm run dev
```

## Форматирование кода

Проверка соответствия кода конфигурации Prettier
```
npm run check-format
```

Запуск форматирование кода
```
npm run format
```

Чтобы включить хук для автоматического форматирования при коммите, нужно прописать:
```
npm run prepare
```
